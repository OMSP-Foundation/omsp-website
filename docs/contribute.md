# Contributing

OMSP is developed in the open in the
[omsp-bootstrap](https://github.com/OMSP-Foundation/omsp-bootstrap)
repository.

## Today

The program currently runs with a single maintainer and a deliberately
strict governance model (human-approved decisions, AI assistance bounded to
an advisory role, evidence-backed validation gates). External contribution
is welcome in these forms right now:

- **Issues** — errors, unclear text, or gaps you find in any published
  artifact: [open an issue](https://github.com/OMSP-Foundation/omsp-bootstrap/issues).
- **Discussion** — questions about adopting the method or the MODS stack.
- **Domain evidence** — references to maritime standards, equipment
  documentation or operational practice relevant to the reference vessel
  (Hanse 460); sources are tracked in a governed source register.

## Later

Accepting external pull-request contributors is an explicit, trigger-based
governance decision (repository-topology ADR, trigger T1 — "community
readiness"). When that trigger fires, contribution guidelines and CLA/DCO
terms will be published here first.

## Working language

Engineering artifacts are written in English; program coordination happens
in Turkish and English. Issues in either language are fine.
